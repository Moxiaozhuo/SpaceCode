## SpaceCode v0.8.10

本版本把重心放在「首次体验 + 权限可信 + 稳定性」三件事上：新增首次打开引导（语言/外观/引擎/模型/工作区一次配好），权限链路补齐计划审批与授权落盘校验，桌面端切到完全信任前会先说明权限范围；同时集中修复了自动重试吞消息、Pi 历史会话接续、思考开关静默失败、office 文档预览与进程清理等一批高频问题。性能侧根治了追踪页白屏卡顿。

## Highlights

- **首次打开引导**：新装即进入向导，依次配置语言、外观、引擎、模型与工作区，模型档位复用设置页的模型列表与可搜索下拉
- **计划审批卡片**：ExitPlanMode 走专用权限卡片，计划正文按 Markdown 渲染；输入为空时不再崩溃
- **权限范围确认**：切到「完全信任」前先弹出权限范围说明，避免误开全量授权
- **授权真正落盘**：`allowPermission` 贯通 `updatedPermissions` / `permissionSuggestions`，会话级与永久授权直达引擎；权限模式按会话归属并回读校验，多会话之间不再串扰
- **macOS Computer Use**：支持 `CuaDriver.app` 包安装与权限分组，驱动新增 doctor 自检与 restart
- **打包链路加固**：打包前预下载 cua-driver 与 OfficeCLI 二进制并做校验，下载失败可用 `--strict` 直接终止
- **会话体验**：会话菜单「分屏」真正打开分屏；工作目录只对空会话开放，发过消息即锁定
- **默认工作区**：新增 `openDefaultProject` 流程，默认工作区不可用时给出应用内气泡提示
- **思考链路**：代理层支持 `reasoning_content` 透传，ChatInput 给出「思考开关下一轮生效」提示
- **会话恢复**：恢复时补齐任务终态，任务卡片不再停留在「运行中」
- **设置保存**：GUI 设置改为排队落地，连续保存不再互相覆盖；配置方案更新/删除需等主进程确认才算成功
- **开发效率**：新增 `test:changed` 脚本，只跑受改动影响的测试

## Fixes

- 思考开关切换失败不再被三层吞掉，界面回退开关并给出可见提示
- 修复自动重试后残留僵尸 turn 导致消息被永久吞掉，以及重试时 UI 静默、中止未等待确认
- Pi 历史会话跨进程接续，打开老会话发消息不再是空白会话；恢复带上历史、图片按 ImageContent 内联、上下文窗口改用用户配置
- Pi 工具卡片不再分裂成「Unknown Tool + bash」两行；透传上游失败原因，不再把错误报成「成功的空结果」
- reasoning 的「思考中」在 thinking 块结束时收口，思考文本平滑揭示，消除推理卡片蹦字感
- officecli 用户级副本按版本刷新，cua-driver 基线升到 0.34.0；截图预览可翻页，watch 子进程 spawn 即登记，macOS/Linux 才真杀得到
- 源码启动 `--feature` 名单收回引擎默认名单，摘掉引擎注释禁用的 4 个开关；移除空壳 CONTEXT_COLLAPSE 并恢复 auto compact 判断
- 错误状态码只认带上下文的写法，429/401/403 不再被响应正文里的数字骗过
- 已取消的定时任务不再拉起引擎进程；模型解析按 engineType 分派，Pi 保留真实模型 id
- 产物 `outputs/` 缺失时挂占位监听并如实回报 watcher 状态；预览与产物列表不被迟到结果覆盖，「外部打开」真走系统程序
- 缺失的记忆文件报「不存在」，不再误报路径越界
- 修复 Windows 下 `.cmd` 启动器参数丢失导致会话无法恢复
- 项目级 Hooks 落到当前项目根，开关禁用即时回写且条目不再消失；失效项目根不再建目录
- 换工作目录后 `session.workingDirectory` 对齐引擎实际 cwd；`openProjectByPath` 先归一化路径，避免重复建会话
- 文件树右键重命名接回节点行内编辑；启动闸门等 preload 就位，验证型构建不再清空 `dist-electron`

## Performance

- 根治追踪页白屏卡顿，技能页首次打开提速（P0~P2 全量落地）

- ChatInput 降至 1771 行，自闭合 UI 与提交分支各自归位

- proxyManager 启动逻辑收敛并支持配置取消；移除 `copy-mcp-vendor` 脚本及其构建步骤
- 补测批次覆盖权限服务与卡片、proxyManager 生命周期、进程池权限模式、流式转换、错误处理、打包契约等模块，并同批上调覆盖率地板
