## SpaceCode v0.8.9

本版本围绕「产物预览 + 网关兼容 + 上下文控制」做了一轮集中打磨：新建产物即时自动预览、Office 文档直接内嵌渲染，代理层的中文流式乱码与 SSE 事件边界问题彻底修复，同时扩展思考参数可按网关族自动适配，模型上下文窗口也支持自定义覆盖。

## Highlights

- **产物自动预览**：文档/HTML 创建即自动打开预览；Office 文档内嵌渲染，PDF 默认回退 HTML，其余文档默认 watch 实时模式
- **产物工作区根扫描**：产物列表新增作用域扫描能力，跨目录产物不再漏显示
- **扩展思考参数映射**：thinking 参数按网关族自动转换，并支持运行时切换思考等级
- **上下文窗口覆盖**：可在设置里覆写模型上下文窗口，上下文用量随设置实时刷新
- **工作区文件选择器**：附件菜单可直接浏览并选取工作区内文件
- **网关能力补齐**：实现 /v1/messages/count_tokens 端点
- **权限链路改造**：权限请求引入 requestId 与 extensions 全链路透传，移动端授权/拒绝与扫码登录更可靠
- **H5 安全加固**：新增敏感数据泄露与 SSRF 防护，本地预览服务只服务登记过的工作区并移除通配 CORS
- **设置项扩充**：新增技能管理入口开关与 Review Agent 选项
- **桌面生命周期**：窗口关闭行为与应用退出流程按生命周期收敛

## Fixes

- 运行中会话对账启动配置，设计系统/技能与 API Key 变更真正生效
- 超长 system prompt 改走 --system-prompt-file，不再 spawn ENAMETOOLONG
- 代理流式 UTF-8 跨分块解码，中文正文不再碎成替换字符
- 代理 SSE 解析器支持 CRLF 事件边界，标准网关流不再被吞空
- 设计导出 ZIP/PDF 真实产出产物，失败不再假装成功
- 设计预览改走预览服务器 URL，多文件设计的相对 CSS/JS 生效
- 设计模式两个下拉浮层改到 body 定位，不再被右侧产物面板遮挡
- 修复流式响应错误处理与活跃轮次检查逻辑
- 修复会话切换时旧检查点响应覆盖新状态的问题
- 办公文档创建即自动预览，修复 watch 残留进程导致的启动超时
- 编排节点启动异常收口为 failed，释放画布结构锁
- 丢弃更改按 HEAD/索引/未跟踪三组分别执行并如实上报失败
- 修复上下文用量大小显示与引擎侧模型上下文窗口赋值错误
- tool_calls 函数参数支持 JSON 对象解析

## Refactor

- 上下文用量 store、Modal、Chip 移除多余 loading 状态，窗口计算统一走设置 store
- 权限处理统一收敛到 requestId
- ArtifactsPanel 文件跟踪与可预览判断逻辑精简
- H5PathGuard 抽离路径归一化函数并增加符号链接能力检测
- saveSettings 重构并补充文档与错误处理，代理保存返回真实状态
- 日志新增 safeConsoleWrite 控制台守卫

## Tests

- 补齐 10+ 个低覆盖模块的单元测试（错误分类、SSE 解析、产物作用域、上下文窗口、轮次检查点、应用生命周期等），并同批上调覆盖率地板
